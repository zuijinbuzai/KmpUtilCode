# 路线图与范围

## 当前首版已实现

9 个能力模块、聚合依赖、Android/iOS/JVM 三端宿主、17 组共享示例、中文模块说明、JVM 行为测试、Android 构建和 Apple 编译链。具体 API 以索引和代码为准。

## 后续优先级

| 阶段 | 候选模块 | 验收要求 |
|---|---|---|
| 0.2 工程化 | API/二进制兼容检查、Dokka、Maven Central 签名发布、依赖锁定 | 可重复发布、兼容性报告、真实发布坐标 |
| 0.3 数据能力 | DataStore/SQLDelight 适配、流式文件/下载、磁盘缓存/TTL | 数据迁移、失败恢复、并发一致性和大文件测试 |
| 0.4 平台能力 | Keychain/Keystore、授权流程、通知、应用/电池/语言/网络监听 | Android/iOS 原生实现、生命周期与拒绝权限 Demo |
| 0.5 媒体与设备 | 图片处理、相机、扫码、定位、蓝牙、震动/音频 | 真机矩阵、后台限制、资源释放和隐私说明 |
| 0.6 UI 配套 | Compose Multiplatform 表单/列表/主题/反馈组件 | 独立 UI 模块，避免核心库依赖 UI 框架 |
| 后续目标 | JS/Wasm、更多 Native/Intel simulator、Swift 取消桥接 | 对等实现、对应 CI 与 Demo，不只声明 target |

这些是方向，不是已交付 API 或发布时间承诺。新增能力应按“公共语义 → 平台适配 → 边界测试 → Demo → 文档”完整交付。

## 不做的默认行为

不全局持有 Activity、不申请全部权限、不读取永久硬件 ID、不后台自动上传、不关闭 TLS 校验、不自动重试非幂等业务、不用自制密码算法替代平台安全存储。
